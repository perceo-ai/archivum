# Modular Wood Desk Organizer + Glass Whiteboard — Assembly + Power Checklist

> Deliverable for build-queue task: “Assembly + finish + installation checklist (revisions + quick test)” (assigned_to: wrench)

## 0) Safety first (do this before any wiring)
- **Unplug from the wall** any time you open/adjust the power module.
- If anything feels off (crushed wire, loose ground, burned smell, damaged insulation), **stop** and troubleshoot before continuing.
- For electrical work: follow your **kit’s manual** and local code. If you’re not comfortable, use a qualified electrician.

## 1) Parts + prep checklist
- Inventory all components and confirm you have:
  - organizer frame/body parts
  - glass/whiteboard panel + mounting hardware
  - cable management covers/rails
  - **cable retractable module** (and its mounting brackets/cord routing pieces)
  - power module (outlet and/or USB), strain relief/grommet(s), wiring harness as provided
- Inspect wiring and connectors for damage.
- Prepare tools: screwdrivers/hex bits, drill bits only if your kit requires it, clamps, soft cloth, microfiber, and (for the safety test) a **multimeter** (recommended).

## 2) Step-by-step assembly (frame → panels → cable module)
### 2.1 Assemble the base frame
1. Dry-fit the main wood frame pieces so you understand orientation.
2. Pre-fit internal cable paths/rails (so you don’t trap anything later).
3. Fasten the structural sections using the kit’s hardware in the order recommended by your instructions.
4. **Check squareness** (measure diagonals if helpful) before fully tightening.

### 2.2 Install internal cable-management rails/covers
1. Route the provided cable/cord path channels as specified.
2. Mount any internal guides so the cable will not get pinched when the retractable module is installed.
3. Leave access space for connecting the retractable module’s wiring/harness.

### 2.3 Install the glass/whiteboard panel (non-wiring step)
1. Clean glass seating surfaces with a soft, lint-free cloth.
2. Install gaskets/pads where required so the panel doesn’t contact wood directly.
3. Mount the panel with the provided brackets/hardware.
4. Confirm the panel seats evenly (no rocking).

## 3) Cable retractable module installation (step-by-step)
> Goal: secure the module, maintain cable bend radius, and ensure smooth retract/extend without snagging.

### 3.1 Mount the retractable module
1. Identify the **module bay** (left/right) and the correct mounting orientation (usually the retraction direction and cord outlet direction matter).
2. Position the module so the cord exits in the intended direction through the cable path.
3. Fasten the module brackets to the frame (don’t overtighten plastic components).
4. Verify the module base is fully seated—no flex.

### 3.2 Route the cable correctly
1. Route the cord through the provided guides/grommets.
2. Avoid sharp bends: keep a gentle radius through corners.
3. Ensure the cord won’t be crushed by closing covers, tightening panel trim, or glass seating hardware.

### 3.3 Check retract/extend limit behavior
1. With the power module still **unplugged**, gently extend the cord partway.
2. Slowly retract to ensure:
   - retraction is smooth (no grinding)
   - the cord isn’t rubbing metal edges
   - the cord doesn’t twist aggressively
3. If your kit includes “limit stop” adjustment, set it so the cord stops cleanly at full extension without yanking.

## 4) Module swapping checks (so future changes don’t break alignment)
> Goal: make swaps repeatable and prevent accidental connector mismatch or cable strain.

1. **Label switch positions** (if your design has switchable modules): mark the correct left/right or A/B positions with a small, durable label.
2. Power off/unplug before any swap.
3. Disconnect connectors using the kit’s intended method (avoid pulling on wires).
4. Confirm keyed connector alignment (no forced insertion).
5. After reinstallation, perform a “mechanical fit check”:
   - module sits flush
   - screws/brackets are fully tightened
   - covers close without pinching the cable
6. Perform a short electrical functional check (see **Quick safety test**).

## 5) Power installation checklist (strain relief, grounding, routing)
> Treat this like a pre-flight checklist.

### 5.1 Strain relief + ingress protection
- Use the **grommet/strain relief** exactly as provided.
- The cord should pass through the designed entry point; **no bare wire should be exposed** at entry.
- Clamp/relieve so pulling on the cord transfers force to the frame/relief, not to terminal connections.

### 5.2 Grounding (critical)
- Verify the ground/earth connection is made to the designated grounding point on the power module.
- If a grounding lug/screw is provided, ensure it is tightened and free of paint/oxidation where contact is required (if applicable per your kit).

### 5.3 Routing + cover closure
- Route wires so they cannot contact moving parts of the retractable module.
- Ensure wires are not pinched by:
  - panel brackets
  - cover trim
  - glass mounting hardware
- Before fully closing, do a “twist and tug” check: lightly tug to confirm nothing is loose.

### 5.4 Labels + position verification
- Label switch positions (e.g., retractable bay A/B or which outlet corresponds to which switch).
- Confirm the power switch toggles the correct outlet/USB output (see quick test below).

### 5.5 Before final power-on
- Double-check:
  - all connectors seated
  - no exposed copper
  - strain relief secured
  - grounding present

## 6) Quick safety test (before full load)
> Run this sequence before plugging in heavy/normal-use devices.

### 6.1 No-load functional + sanity checks
1. **Unplug wall power** before initial wiring verification.
2. Inspect visually: no pinched wires, no loose screws near terminals.
3. Power on and test with **no load** (nothing plugged in):
   - Turn each switch ON/OFF and verify expected indicator lights (if present).
   - Listen/feel for unusual buzzing, arcing, or heat buildup.

### 6.2 Ground continuity (recommended)
- Using a multimeter (if available), verify ground continuity from the grounded terminal/pin to the module’s grounding point.
- Target values depend on your meter and setup; **anything wildly off** should stop the install and trigger troubleshooting.

### 6.3 GFCI test (if your wall outlet uses GFCI)
1. If available, plug into a **GFCI-protected** outlet.
2. If the system supports a test function, run the test/reset cycle.

### 6.4 5-minute thermal check
1. Leave the unit on with no load for ~5 minutes.
2. Check for:
   - warm/hot smell
   - abnormal heat near the power module/terminals
   - buzzing/crackling

### 6.5 Low-load then normal-load progression
1. Plug in a low-power device first.
2. Then step up gradually to expected normal loads.
3. If anything unusual appears at any stage, power off and investigate.

## 7) Completion notes (what “done” looks like)
- Cable retract/extend is smooth with no snagging.
- Module swap fits cleanly and connectors align without forcing.
- Power install passes grounding/strain relief checks.
- Quick safety test is clean (no arcing, no overheating, switches correct).
