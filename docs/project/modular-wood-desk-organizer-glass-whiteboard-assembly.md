# Modular Wood Desk Organizer + Glass Whiteboard — Assembly / Finish / Installation Checklist

**Owner:** wrench  
**Project:** Modular Wood Desk Organizer + Glass Whiteboard

## Purpose
Provide a safe, repeatable build checklist for the combined system:
- modular wood desk organizer
- glass whiteboard mounting hardware
- power routing / safety checks

Use this as the “do not start drilling or finishing until verified” gate.

---

## 0) Safety gate (read first)
- [ ] If anything will touch mains power: **unplug at the outlet** before any routing/drilling.
- [ ] Wear eye protection when drilling/cutting.
- [ ] Plan fastener locations so you **never drill into** the cable path.
- [ ] Use strain relief any time a cable transitions from a moving/loaded surface to a fixed one.

---

## 1) Inputs / measurements (capture before cutting)
Record these in your build log:
- [ ] Desk organizer dimensions needed for your layout (L/W/H)
- [ ] Glass whiteboard mounting interface geometry (hole locations or frame/backer interface)
- [ ] Rail/module placement datums (centerline height, left/right rail datum lines)
- [ ] Outlet / power strip locations + working clearance (plug insertion + service access)
- [ ] Cable run routes (shortest safe route + avoid sharp edges + avoid pinch points)

---

## 2) Parts & tools readiness check
### Parts
- [ ] Organizer module hardware (rails/brackets/fasteners as designed)
- [ ] Isolation pads/gaskets (EPDM/rubber) for glass interface
- [ ] Spacer set (non-marring surfaces)
- [ ] Anchors/fasteners appropriate for your substrate (studs/plywood/MDF/etc.)
- [ ] Cable management parts (clamps, grommets, cable raceway/track as designed)
- [ ] Strain relief parts (grommets + rated strain relief / cord clamp)

### Tools
- [ ] Measuring tape + marker + square
- [ ] Drill + appropriate bits
- [ ] Driver/torque driver (recommended)
- [ ] Laser level (or long level)
- [ ] Multimeter (recommended for continuity/ground checks)

---

## 3) Wood assembly (organizer modules)
Do this before final finishing.

1. [ ] Dry-fit modules to confirm alignment datums.
2. [ ] Mark drill points; double-check against cable clearance zones.
3. [ ] Pre-drill to prevent splitting.
4. [ ] Assemble with fasteners per design; tighten in stages (don’t fully torque until everything is seated).
5. [ ] Verify:
   - [ ] Module corners are square (within your tolerance)
   - [ ] Rails land on the same reference lines across the full length
   - [ ] Any sliding/retractable module movement is unobstructed

---

## 4) Finish preparation (before final assembly into the installation position)
- [ ] Sand surfaces to desired grit; remove dust.
- [ ] Edge-protect exposed wood (seal edges before/after stain/paint as your finish system requires).
- [ ] Test stain/paint/clear coat on scrap.

---

## 5) Finishing (do not rush curing)
Use your chosen system (stain/paint/varnish), but keep the sequence consistent.
- [ ] Apply finish evenly (thin coats).
- [ ] Let cure fully per manufacturer guidance.
- [ ] If a coat is tacky longer than expected, **stop** and investigate—don’t trap uncured finish under mounted parts.

---

## 6) Cable + power installation checklist (glass/rail zone)
### Routing
- [ ] Confirm cable run keeps at least “service clearance” so plugs can be inserted/removed.
- [ ] Use grommets/clamps where cables pass through or near wood edges.
- [ ] Keep cables away from sharp hardware edges; add edge protection if needed.
- [ ] Ensure no cable is pinched when modules are installed or moved.

### Strain relief & grounding
- [ ] Add strain relief at transitions from outlet/power strip to fixed internal routing.
- [ ] Ensure grounding continuity if your system includes any metal chassis/rails (recommended: multimeter continuity).

### Labeling & switch position awareness
- [ ] Label power switch positions and “which module they control”.
- [ ] If you’re using multiple supplies/ports, confirm “off” actually isolates the intended load.

---

## 7) Glass whiteboard mounting (mechanical checklist)
This is the “don’t stress tempered glass” gate.
- [ ] Install vertical rails using shim tolerance.
- [ ] Verify rails are plumb before any final tightening.
- [ ] Dry-fit with spacers/gaskets; ensure smooth seating without forcing.
- [ ] Final tightening in gradual/even passes.
- [ ] Confirm isolation pads are fully seated (no pinching).
- [ ] Verify no glass edge contacts sharp metal.

(If you need the deeper mounting verification procedure, see the main integration plan.)

---

## 8) Installation into final position
- [ ] Move/position assembly without snagging cables.
- [ ] Re-check:
  - [ ] Mounting alignment (centerline + leveling)
  - [ ] Fastener tightness after settling
  - [ ] Cable slack/routing (no stress on connectors)

---

## 9) Quick safety test (before full load / long-term use)
### Visual + mechanical (no power)
- [ ] Unplug power.
- [ ] Inspect strain relief and cable clamps (no tugging load on connectors).
- [ ] Check fasteners again for any obvious looseness.

### Power-on “smoke test”
- [ ] Plug in.
- [ ] Power on and observe for **1–2 minutes**:
  - [ ] No unusual heat at connectors or near routing paths
  - [ ] No flicker/noise indicative of unstable connection
  - [ ] No pinched cables or shifting under light movement
- [ ] Power off and confirm everything stayed secure.

---

## 10) Completion documentation (what to save)
- [ ] A one-page measurement sheet (W/H/T + mounting point distances)
- [ ] A photo set:
  - rails/modules installed and level
  - cable routing + strain relief points
  - dry-fit vs final mounting photos
- [ ] Notes about any deviations (what you changed and why)

---

## Troubleshooting quick checks
- If alignment drifts after tightening: loosen slightly, verify rail plumb, shim, then re-tighten evenly.
- If cable routing feels tight: re-route early—don’t rely on “it will flex” for long-term use.
- If you see heat buildup: stop, unplug, and correct connector/clearance issues before continuing.
